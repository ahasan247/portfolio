# Portfolio plan

## Purpose
Present Ahasanul Hoque as a backend-first software engineer who can implement end-to-end business requirements, work on data-sensitive operational systems, and ship changes in production. The design is suitable for international engineering recruiters, consulting clients, and fellow developers.

## Site structure

1. **Hero** — precise professional positioning, a clear call to action, and an illustrated request-flow diagram.
2. **Selected work** — six case-study summaries with functioning filters for Backend, Platforms and DevOps.
3. **Expertise** — four technical capability groups, with concise and accurate tool names.
4. **About** — education, professional timeline, and engineering values.
5. **Contact** — Upwork link immediately functional; email, GitHub and LinkedIn appear when configured.

## Visual approach
Editorial typography, light warm background, deep navy surfaces, lime accents, technical illustration built with CSS. Responsive layout covers desktop, tablet and mobile. No JavaScript frameworks, build tools, backend, or paid hosting required.

## Content and privacy review

- All public-facing claims should be approved by the site owner.
- Employer and platform names appear only at a high level; proprietary implementation specifics and client information are excluded.
- Cloud & Infrastructure Lab is explicitly described as practice, not production client work.
- No unverified percentages, customer counts, ROI figures, or invented testimonials.
- Add project screenshots and public GitHub repositories only with appropriate permission.
