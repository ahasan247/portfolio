# Ahasanul Hoque — Developer Portfolio

Modern, responsive, dependency-free portfolio highlighting professional backend engineering work, enterprise systems, Laravel/PHP, REST APIs, SQL, and DevOps practice.

## Live site

Once GitHub Pages is enabled: **https://ahasan247.github.io/portfolio/**

## View locally

Open `index.html` directly in Chrome, or run `python -m http.server 8000` from the repository root, then visit http://localhost:8000.

## Publish using GitHub Pages

1. Open [Settings → Pages](https://github.com/ahasan247/portfolio/settings/pages).
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main** and **/(root)**.
4. Click **Save** and check deployment status in the repository's Actions tab.

## Customize

- **`index.html`** contains the full website with embedded CSS and JavaScript, avoiding dependencies or build configuration.
- Search for `window.PORTFOLIO_CONFIG` near the top of the file to add your professional email and LinkedIn URL. The GitHub and Upwork profiles are linked already.
- Update project descriptions, role history, and skills in the HTML as your career evolves.
- Check all statements for accuracy, and respect employer/client confidentiality.

## Notes

The former Laravel portfolio repository was renamed to `ahasan247/portfolio-old` and is not used for this site. This is a public static website with no database, tracking, or backend requirement. Fonts load from Google Fonts if the user has network access.
